## Commit messages and a review before you commit

In the Source Control view, two buttons sit in the title bar:

- **Write Commit Message with Gisoo** reads the staged changes (or all changes when nothing is staged) and writes the message in the style of your recent commits.
- **Review My Changes with Gisoo** looks for bugs, security problems and missing tests before you commit.

## پیام کامیت و مرور پیش از کامیت

در نمای Source Control دو دکمه در نوار بالای آن هست:

- **نوشتن پیام کامیت با گیسو** تغییرهای Stage‌شده را می‌خواند (اگر چیزی Stage نشده باشد، همهٔ تغییرها را) و پیام را به سبک کامیت‌های قبلی شما می‌نویسد.
- **مرور تغییرهای من با گیسو** پیش از کامیت دنبال باگ، مشکل امنیتی و تست‌های جاافتاده می‌گردد.
